# FrameFlow Studio UI/UX 개편 기준

## 검토 범위

- 프로젝트 목록
- 프로젝트 상세, 씬, 컷 카드, 연속 영상 영역
- 컷 편집, FLF/Ref2VA 생성 모드, 이미지 및 대표 영상, 프롬프트
- LLM 메타 프롬프트 작업공간과 Video-to-Audio LLM 작업공간
- MiniMax-H3 생성 설정 및 실행 전 검증 창
- Video-to-Audio 입력, 생성 큐, 결과 카드
- 전체 생성 큐
- Comfy Desktop, 프로젝트 저장, FFmpeg 설정
- 최대 창 1920×1080 및 최소 지원 창 1180×720

## 발견한 문제

1. 최대 창에서 프로젝트 목록과 설정 화면의 콘텐츠가 한쪽에 몰려 큰 빈 공간이 생겼다.
2. 최소 창에서 236px 사이드바가 작업영역을 과도하게 차지했다.
3. 씬에 생성·테스트·연속 생성·합본·내보내기 버튼이 같은 위계로 나열되어 작업 목적이 보이지 않았다.
4. 프로젝트 헤더와 빈 연속영상 영역이 세로 공간을 많이 차지해 첫 컷이 늦게 보였다.
5. 컷 편집은 긴 스크롤 끝에서만 생성 버튼에 도달할 수 있었다.
6. 설정 화면은 주 설정 영역이 좁고 안내 영역이 지나치게 넓었다.
7. 카드, 모달, 선택 상태, 빈 상태의 간격과 강조 규칙이 화면마다 달랐다.

## 적용 원칙

- 한 화면에는 하나의 명확한 주 행동만 coral 색으로 강조한다.
- 보조 행동은 mint outline, 위험 행동은 red tint로 구분한다.
- 씬 행동은 `컷별 생성`, `연속 생성`, `파일` 세 그룹으로 묶는다.
- FIRST/LAST와 대표 영상 썸네일은 일관된 비율과 상태 배지를 사용한다.
- 컷 생성 버튼은 편집창 하단에 고정해 어느 위치에서도 실행할 수 있게 한다.
- 최대 창은 1680px 작업 폭을 활용하고 카드 수를 자동 확장한다.
- 1280px 이하에서는 사이드바를 76px 아이콘 모드로 자동 축소한다.
- 1180×720에서는 세로 여백과 헤더 높이를 줄여 핵심 콘텐츠를 먼저 보여준다.
- 설정은 주 설정 2열 + 빠른 시작 안내 1열로 배치하고, 좁아지면 순서대로 쌓는다.
- 모든 모달은 내부 스크롤과 고정 하단 행동 영역을 사용한다.

## 기능 보존

생성 큐, Comfy 실행, FLF/Ref2VA 워크플로, 파일 저장, LLM 프롬프트 및 MiniMax-H3 옵션의 데이터와 동작은 변경하지 않는다. 이번 개편은 정보 구조, 시각 위계, 반응형 레이아웃과 접근성 표현에만 적용한다.
