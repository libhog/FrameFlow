# 이미지/영상 개선 (실험적)

메인 메뉴에서 이미지·영상 파일을 선택하고 NeuralScreen 외부 런타임으로 처리합니다.
화면/데스크톱 캡처는 하지 않으며, 원본이나 기존 결과를 덮어쓰지 않습니다.

## 사용

1. NeuralScreen 폴더를 지정합니다. `main.py`, `guides.py`, `native/nvngx.dll`,
   `native/nvngx_dlssnr.dll`이 필요합니다. NVIDIA DLL은 FrameFlow에 동봉하지 않습니다.
2. Python을 자동으로 찾지 못하면 해당 런타임의 `python.exe`를 지정합니다.
   `av`, `numpy`, `cv2`가 필요하며 자동 설치하지 않습니다.
3. 연결 확인은 파일 존재만 검사합니다. GPU 호환성은 한 프레임 미리보기로 확인합니다.
   비교하기/개선 실행 클릭 시 아직 확인되지 않은 연결은 자동 확인하며 실패 이유를 표시합니다.
4. 여러 파일 추가 → 목록에서 선택 → 약하게/기본/강하게/Custom → 저장 폴더 → 선택 파일 개선 실행.
   비교하기는 업로드된 모든 파일을 전용 비교창에서 확인합니다. 영상은 첫 프레임만 처리하며 이전/다음으로 파일을 이동합니다.
   100%/200%만 제공하고 화면에 맞춰 축소하지 않습니다. Windows DPI를 보정해 물리 화면 픽셀에 대응합니다.
   큰 이미지는 드래그로 이동하고 가운데 손잡이로 비교선을 이동합니다. 파일별 배율·위치를 유지합니다.
   옵션 보기에서 설정을 바꾼 후 현재 설정으로 비교를 누르면 같은 위치에서 다시 보정합니다.
   Custom은 기준 Profile과 Intensity / Local tone / Local structure / Skin structure를 저장합니다.
   메인 설정과 비교창에서 이름을 지정해 내 프리셋을 저장·불러올 수 있습니다. 동일 이름은 덮어쓰지 않습니다.
   비교창의 옵션 패널은 기본으로 열리고 설정 적용 버튼으로 재처리합니다.
   처리 방식: NR만(기본), ReShade만, ReShade → NR. 프리셋은 처리 방식과 양쪽 설정을 함께 저장합니다.
   ReShade는 노출(EV)·감마·대비·채도를 실제 ReShade FX에서 보정합니다. 기본값은 원본 유지입니다.
   비교창에서도 처리 방식과 색상을 변경하고 설정 적용을 눌러 다시 확인할 수 있습니다.
   미리보기와 결과 보기에서 원본/결과를 드래그 슬라이더로 비교합니다. 영상 비교는 동기 재생합니다.
5. 한 번 실행한 모든 PNG/MP4(H.264) 결과가 공통 `enhance-시간값` 폴더에 저장됩니다.
   동일한 이름의 입력은 작업별 접두어로 구분하며 덮어쓰지 않습니다. `.work`의 임시 파일은 종료 시 정리됩니다.
   영상 오디오는 AAC로 인코딩합니다. 비교 이미지는 앱 캐시 폴더에 잠시 저장하고 비교창을 닫으면 정리합니다.
   작업 실패·취소 시에도 이번 실행에서 만든 작업 폴더를 정리합니다. 기존 파일이나 원본은 삭제하지 않습니다.
   모든 작업 종료 시 실행 마커와 빈 결과 폴더도 정리합니다. 최종 결과 파일과 UI 오류 기록은 유지합니다.
6. 실행별 결과 카드 안에 완료/실패/취소 목록과 보기·파일 위치·결과 폴더 열기가 표시됩니다.
   일부 파일 실패 시 나머지는 계속 처리합니다. 전체 취소는 현재 작업과 아직 시작하지 않은 작업을 중단합니다.
   입력 목록에서 제거하거나 목록을 비워도 실제 입력 파일과 기존 결과는 삭제하지 않습니다.
7. 입력 목록은 저장하지 않으며 앱 실행마다 초기화됩니다. 성공한 항목은 입력 목록에서 자동 제거합니다.
   실패·취소된 입력은 현재 실행에서 재시도할 수 있게 남습니다. 완료 결과 기록과 설정·프리셋은 유지합니다.

## 제한

- NR은 Windows 11, RTX 50 계열용 실험 연결입니다. `NS_ARCH_SPOOF=0`으로 비공식 GPU 우회를 비활성화합니다.
- ReShade만 모드는 D3D11 GPU와 Python(av, numpy)만 필요하며 NeuralScreen은 필요 없습니다.
  ReShade 6.8.0 Add-on 버전 ReShade64.dll 경로를 지정하거나 앱 옆 tools/reshade/ReShade64.dll에 둡니다.
  다른 버전은 SDK ABI가 달라 명확히 거부합니다. 게임에 ReShade를 주입하거나 시스템에 설치하지 않습니다.
  ReShade만/병행 모드는 가로 160px 또는 세로 120px 이상이어야 합니다(엔진 최소 크기).
  개인 PC용 런타임은 공식 설치 파일에서 추출했습니다. 다른 사용자에게 배포할 때는 공식 사이트의 다운로드/배포 조건을 확인하고 원본 다운로드 링크를 제공하세요.
  자체 숨김 렌더러와 FrameFlowColor.fx만 연결합니다. 임의 ReShade 프리셋/셰이더, LumeniteFX, DLSS5 Feeder, 깊이 기반 효과는 지원하지 않습니다.
- NeuralScreen D5V3/FRM1/OUT1 프로토콜 기준 (2026-09-10 소스 확인).
- Resolution은 Full 고정입니다. 네트워크 축소 모드를 끕니다(`NS_NR_SMALL=0`).
  가이드/feature 작업 크기에는 호환성 상한 2560×1440을 유지하지만 NR 색상 입력과 출력은 원본 전체 크기입니다.
  저장 해상도도 입력과 같습니다. 이 기능은 해상도를 늘리는 업스케일러가 아닙니다.
- HDR은 지원하지 않습니다. 가로·세로 64~8192px, 총 34MP 이하를 허용합니다.
- 렌더링 결과의 정확도·일관성은 런타임과 GPU에 의존하며 원본 보존형 복원을 보장하지 않습니다.
- 작업 중 앱의 정상 종료를 막아 완료 또는 취소를 안내합니다.
  부모 앱 종료 감시와 프레임 120초 응답 제한으로 자체 하위 프로세스만 정리합니다.
- 배포/사용 권한은 사용자가 확보해야 합니다. 비상업용이라는 이유로 NVIDIA 런타임의 권한이 자동 부여되지는 않습니다.

## 검증

- `verification/media-enhance.mjs`: 실제 화면에서 1180/1440/1920px, 스크롤, 메뉴.
  모듈 단위 모의 native transport로 다중 선택/중복 제거/순차 처리/공통 폴더/
  미리보기/결과 목록/부분 실패/대기 취소/Custom 값 전달·저장/비교 슬라이더 검증.
- Rust `enhance::tests`: 같은 이름의 두 입력이 같은 결과 폴더에 별도 파일로 저장되고 덮어쓰기가 거부되는지 검증.
- `verification/neural-adapter-test.py`: 실제 PyAV/FFmpeg, 모의 신경망 worker로
  PNG 알파, 원본 불변, 덮어쓰기 거부, VFR 타임스탬프, 취소 검증.
- `verification/navigation-history.mjs`: 기존 뒤로/앞으로가기 회귀 검증.
- `cargo check`: 네이티브 명령 컴파일 검증.
- `verification/reshade-native-test.py`: 실제 ReShade D3D11 중립값 및 +1EV 픽셀 검증.
- `verification/reshade-pipeline-test.py`: 실제 ReShade 이미지/영상 처리, 알파/원본/VFR 보존 및 NR 입력 순서(모의 NR) 검증.
- NR 자체의 실제 GPU 추론은 이번 검증에 포함하지 않았습니다.
